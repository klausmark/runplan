          Workout YAML syntax

          id, day, name, and a non-empty steps list are required. description is optional. IDs use lowercase letters, numbers, and hyphens; days are 1–7 and must be free within the week.

          Actions: warmup, run, recovery, cooldown, and repeat. Time examples: 30s, 5m, 1h. Distance uses an explicit field, such as {distance: 400m} or {distance: 1.5km}.

          - run: {time: 8m, pace: "4:30-4:45 min/km"}
- repeat:
    count: 5
    steps:
      - run: {distance: 400m}
      - recovery: 90s
